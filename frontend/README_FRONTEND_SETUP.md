# Lets-do-it full project setup

Backend is in the repository root and frontend is in `frontend/`.

## Backend
Run from the root folder:
`npm install`
`npm run dev`

Configure backend `.env` (use `.env.sample` as reference). For frontend development, set `CORS_ORIGIN=http://localhost:5173`.

## Frontend
`cd frontend`
`npm install`
Copy `.env.example` to `.env` if needed.
`npm run dev`

Vite typically opens at http://localhost:5173.
